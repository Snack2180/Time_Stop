TIME STOP v3 — GitHub Pages 업데이트 안내

1. ZIP 압축을 풉니다.
2. GitHub 저장소 Snack2180/Time_Stop의 Code 탭으로 갑니다.
3. 기존에 있는 index.html과 sw.js를 이번 파일로 교체합니다.
   - GitHub 웹 UI에서 파일 클릭 > 연필 아이콘(Edit) > 전체 내용을 새 파일 내용으로 바꾸는 방식도 가능합니다.
   - manifest.webmanifest과 icon-192.png, icon-512.png도 함께 업로드해도 됩니다.
   - index.html은 반드시 저장소 최상단(root)에 있어야 합니다.
4. Commit changes를 누릅니다.
5. Actions 탭에서 Pages 배포가 완료(초록 체크)될 때까지 기다립니다.
6. 아이패드 Safari로 기존 Pages 주소에 접속해 새로고침합니다.
7. 홈 화면의 TIME STOP을 완전히 종료한 뒤 다시 실행합니다.
   - 오래된 화면이 계속 보이면 Safari 사이트에서 한 번 더 새로고침하고, 잠시 뒤 홈 화면 앱을 다시 열어보세요.

v3의 새 기능
- GOOD 이상 연속 성공 시 콤보 +1; MISS/TIME OUT 시 0으로 초기화
- 연속 콤보는 앱을 다시 열어도 저장됨
- 총 12개 업적 (숫자 패턴 / 퍼펙트 / 콤보 / 플레이 횟수 등)
- 업적은 달성 즉시 결과 화면에 표시
- 전체/쉬움/보통/어려움 별 기록 필터
- 기록/업적 화면의 돌아가기 버튼과 TIME STOP 로고로 메뉴 이동
- v2 기록과 업적을 같은 사이트 주소에서 업데이트할 경우 v3로 이전

주의
- 기록, 업적, 콤보는 각 기기 브라우저 내부 저장소(localStorage)에 저장됩니다.
- 다른 기기에 자동 동기화되지 않으며, Safari의 사이트 데이터 삭제 시 초기화될 수 있습니다.
- 저장된 기록은 최근 최대 1000회 분량입니다.
- 타이머는 performance.now() 기준으로 계산합니다. 화면 출력은 기기 성능에 따라 갱신 주기가 달라질 수 있습니다.
