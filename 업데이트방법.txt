TIME STOP PWA v2

추가 기능
1. 내 기록
- 모든 난이도 기록 통합
- 절대 오차가 작은 순서로 자동 정렬
- 같은 오차라면 어려운 난이도를 우선 배치
- 브라우저 localStorage에 최대 200개 저장

2. 자동 종료
- 목표 시간을 다음 10초 단위로 올림한 시점에 자동 종료
- 현재 목표 시간은 항상 10초 미만이므로 10초에서 자동 종료

3. 업적
- 같은 숫자: 7.77처럼 같은 숫자가 3번 이상 연속된 랜덤 목표를 완료
- 순서대로: 1.23 / 3.21처럼 연속 숫자 3개 이상이 포함된 랜덤 목표를 완료
- 업적용 목표를 강제로 생성하지 않음. 일반 랜덤 목표에서 우연히 나와야 함.

4. 목표시간
- 쉬움: 1.0 ~ 9.9초
- 보통: 1.00 ~ 9.99초
- 어려움: 1.000 ~ 9.999초

GitHub Pages 업데이트 방법
- 기존 저장소의 index.html, sw.js, manifest.webmanifest, icon 파일을 이 버전 파일로 교체
- Commit changes
- Pages가 다시 배포될 때까지 기다림
- iPad 홈 화면 앱을 완전히 종료한 뒤 다시 실행
- 오래된 화면이 남으면 Safari에서 사이트를 한 번 다시 연 뒤 새로고침
